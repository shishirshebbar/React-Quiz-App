# React Quiz Application

## About the Project

This project is an interactive quiz application built using React. It allows users to answer multiple-choice questions, view their progress, and see their final scores. The goal of this project is to provide a simple and engaging way to test knowledge through a responsive and dynamic interface.




## Clone the Repository

To get a local copy of the project, open your terminal and run:

```bash
git clone https://github.com/shishirshebbar/React-Quiz-App.git
cd quiz-app
```

## Setup

Make sure you have Node.js and npm installed. Then install all project dependencies:

```bash
npm install
```

## Start the Application

Run the following command to start the project:

```bash
npm start
```

The application will start and open automatically in your default browser at http://localhost:3000
